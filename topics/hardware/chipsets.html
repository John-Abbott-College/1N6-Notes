Chipsets

How logic gates become chips, and how the chipset, the processor, and main memory are connected

Introduction

We previously learned how information is represented in computer systems (binary and logical circuits). In particular, we saw how simple switches could be used to represent AND, OR, XOR, and NOT logic in electrical devices.

Combining these simple “gates” into more sophisticated devices lets engineers create Integrated Circuits (ICs), or, as we more commonly call them, chips.

Today we finish learning about some of the most important chips in a computer, introduced earlier:

  • Chipsets: the traffic controllers of the motherboard
  • Central Processing Unit (CPU): the brains of the computer
  • Main memory (RAM): the working space of the CPU

From Logic Gates to the Motherboard ⎇

Logic gates are the “atoms” of computing. A single chip can contain a handful of them (like the 7408 quad AND gate, which holds four AND gates in a 14-pin package) or billions of them (like a modern CPU).

When many chips are placed on one circuit board and connected together, we get a motherboard. The Acer T3-710 board below is composed of many integrated components.

The Chipset ⚙️

A chipset is a group of microchips on a computer’s motherboard that manages communication between the CPU, memory, storage, and peripheral devices.

Key functions

  • Controls the data flow between components
  • Determines what hardware (RAM, CPU, GPU, etc.) is supported
  • Manages input/output functions (USB, audio, networking)
  • Affects system performance and upgrade options

In other words, the chipset dictates hardware compatibility across components. All the different hardware components communicate with the CPU through the chipset.

Examples

  • Intel Z790: supports modern CPUs, PCIe 5.0, and DDR5 memory
  • AMD B650: designed for Ryzen processors

How did chipsets evolve?

Older motherboards were designed with many different chips scattered all over the board, each controlling a different function: bus controllers, memory controllers, keyboard controllers, and so on.

As technology progressed, engineers decided to reduce the number of chips and centralize them. The few chips that now do the same job are what we call a chipset.

Northbridge and Southbridge

Most traditional chipsets are divided into two distinct components.

Northbridge Southbridge
Function Connects the CPU to high-speed components (RAM, graphics card, PCI Express) Connects to slower peripheral devices and handles input/output (I/O)
Speed Works faster: optimized for actions per second Works slower: does not need high-speed communication
Location Close to the CPU, often under a heatsink because it runs hot Found lower on the motherboard (hence “south”)
Example connections CPU ↔︎ RAM, CPU ↔︎ GPU (through AGP or PCIe) USB ports, hard drives (SATA/IDE), audio, BIOS, network controllers
NoteWhy is the northbridge faster?

It connects the most used and most important components of the motherboard, so it is optimized for speed. But faster actions per second come at a cost: the northbridge is a source of heat and needs to be cooled by heatsinks and fans.

Modern motherboards and chipsets

Modern chipsets integrate the northbridge directly into the CPU chip. The remaining southbridge functions are handled by a single controller called the Platform Controller Hub (PCH).

New design advantages

  • Sensitive hardware components communicate directly with the CPU
  • Reduces system latency, so data moves faster
  • Increases responsiveness and overall performance
  • Less sensitive hardware (storage, USB) benefits from improved efficiency
TipFun fact

Earlier PCs had separate northbridge and southbridge chips. Modern systems combine them into a single chipset for efficiency.

Buses 🛣️

A bus is the pathway that data uses to travel between components. When we speak about the motherboard bus width, we usually refer to the frontside bus (FSB), the link between the CPU and the northbridge. It is also called the CPU bus or processor bus.

Why is the bus important?

A good way to double-check that you understand a scientific concept is to check what units of measurement it uses.

Highway System bus
How many “lanes”? Number of lanes: a number. Determines how many cars can use the highway at once Bus width: a number of bits (e.g. a 32-bit processor). Determines how much information flows along the bus at a time
How fast? Speed limit: distance per time (e.g. km/h). Determines how fast cars can drive Bus speed: information per time (e.g. bits/second). Determines how fast information can travel

Activity: A highway has 6 lanes (6 cars can pass together). On each lane, 3 cars pass per second. How many cars pass per second on this highway?

CautionExpand to see the answer

6 lanes × 3 cars per second per lane = 18 cars per second.

The same reasoning applies to a bus: width × speed = throughput.

x86 versus x64

x86 (32-bit systems) x64 (64-bit systems)
Data per trip 32 bits can travel at once between system components 64 bits can travel at once between system components
Distinct values 232 ≈ 4.3 billion 264 ≈ 18 quintillion
NoteCareful with the numbers

A 32-bit bus moves 32 bits at a time. The figure 232 ≈ 4 billion is the number of different values that 32 bits can represent (for example, memory addresses), which is why 32-bit systems are limited to about 4 GB of RAM.

Almost all modern hardware and software today use the x64 (64-bit) architecture. 64-bit systems offer:

  • 🔒 Better security features
  • 🎨 Improved graphics and performance
  • ⚡ Support for larger amounts of memory

But some older applications still rely on 32-bit (x86) support, so many systems remain backward compatible to run older software.
