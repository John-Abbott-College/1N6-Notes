Chipsets, CPU and RAM

How logic gates become chips, and how the chipset, the processor, and main memory work together inside a computer

Published

September 16, 2025

Modified

October 14, 2026

Introduction

We previously learned how information is represented in computer systems (binary and logical circuits). In particular, we saw how simple switches could be used to represent AND, OR, XOR, and NOT logic in electrical devices.

Combining these simple “gates” into more sophisticated devices lets engineers create Integrated Circuits (ICs), or, as we more commonly call them, chips.

Today we finish learning about some of the most important chips in a computer, introduced earlier:

  • Chipsets: the traffic controllers of the motherboard
  • Central Processing Unit (CPU): the brains of the computer
  • Main memory (RAM): the working space of the CPU

From Logic Gates to the Motherboard ⎇

Logic gates are the “atoms” of computing. A single chip can contain a handful of them (like the 7408 quad AND gate, which holds four AND gates in a 14-pin package) or billions of them (like a modern CPU).

When many chips are placed on one circuit board and connected together, we get a motherboard. The Acer T3-710 board below is composed of many integrated components.

The Chipset ⚙️

A chipset is a group of microchips on a computer’s motherboard that manages communication between the CPU, memory, storage, and peripheral devices.

Key functions

  • Controls the data flow between components
  • Determines what hardware (RAM, CPU, GPU, etc.) is supported
  • Manages input/output functions (USB, audio, networking)
  • Affects system performance and upgrade options

In other words, the chipset dictates hardware compatibility across components. All the different hardware components communicate with the CPU through the chipset.

Examples

  • Intel Z790: supports modern CPUs, PCIe 5.0, and DDR5 memory
  • AMD B650: designed for Ryzen processors

How did chipsets evolve?

Older motherboards were designed with many different chips scattered all over the board, each controlling a different function: bus controllers, memory controllers, keyboard controllers, and so on.

As technology progressed, engineers decided to reduce the number of chips and centralize them. The few chips that now do the same job are what we call a chipset.

Northbridge and Southbridge

Most traditional chipsets are divided into two distinct components.

Northbridge Southbridge
Function Connects the CPU to high-speed components (RAM, graphics card, PCI Express) Connects to slower peripheral devices and handles input/output (I/O)
Speed Works faster: optimized for actions per second Works slower: does not need high-speed communication
Location Close to the CPU, often under a heatsink because it runs hot Found lower on the motherboard (hence “south”)
Example connections CPU ↔︎ RAM, CPU ↔︎ GPU (through AGP or PCIe) USB ports, hard drives (SATA/IDE), audio, BIOS, network controllers
NoteWhy is the northbridge faster?

It connects the most used and most important components of the motherboard, so it is optimized for speed. But faster actions per second come at a cost: the northbridge is a source of heat and needs to be cooled by heatsinks and fans.

Modern motherboards and chipsets

Modern chipsets integrate the northbridge directly into the CPU chip. The remaining southbridge functions are handled by a single controller called the Platform Controller Hub (PCH).

New design advantages

  • Sensitive hardware components communicate directly with the CPU
  • Reduces system latency, so data moves faster
  • Increases responsiveness and overall performance
  • Less sensitive hardware (storage, USB) benefits from improved efficiency
TipFun fact

Earlier PCs had separate northbridge and southbridge chips. Modern systems combine them into a single chipset for efficiency.

Buses 🛣️

A bus is the pathway that data uses to travel between components. When we speak about the motherboard bus width, we usually refer to the frontside bus (FSB), the link between the CPU and the northbridge. It is also called the CPU bus or processor bus.

Why is the bus important?

A good way to double-check that you understand a scientific concept is to check what units of measurement it uses.

Highway System bus
How many “lanes”? Number of lanes: a number. Determines how many cars can use the highway at once Bus width: a number of bits (e.g. a 32-bit processor). Determines how much information flows along the bus at a time
How fast? Speed limit: distance per time (e.g. km/h). Determines how fast cars can drive Bus speed: information per time (e.g. bits/second). Determines how fast information can travel

Activity: A highway has 6 lanes (6 cars can pass together). On each lane, 3 cars pass per second. How many cars pass per second on this highway?

CautionExpand to see the answer

6 lanes × 3 cars per second per lane = 18 cars per second.

The same reasoning applies to a bus: width × speed = throughput.

x86 versus x64

x86 (32-bit systems) x64 (64-bit systems)
Data per trip 32 bits can travel at once between system components 64 bits can travel at once between system components
Distinct values 232 ≈ 4.3 billion 264 ≈ 18 quintillion
NoteCareful with the numbers

A 32-bit bus moves 32 bits at a time. The figure 232 ≈ 4 billion is the number of different values that 32 bits can represent (for example, memory addresses), which is why 32-bit systems are limited to about 4 GB of RAM.

Almost all modern hardware and software today use the x64 (64-bit) architecture. 64-bit systems offer:

  • 🔒 Better security features
  • 🎨 Improved graphics and performance
  • ⚡ Support for larger amounts of memory

But some older applications still rely on 32-bit (x86) support, so many systems remain backward compatible to run older software.

What do the cores of a CPU do?

  • ⚙️ Executing program instructions
  • ➗ Performing calculations
  • 📊 Managing data flow inside the CPU
  • 🤝 Coordinating with other components

A program, up close

Here is a tiny program for an early CPU. Each line of binary is a command, and the commands must be sent in a specific order for the CPU to perform work.

Binary Meaning
10000000 The next line is a number, put it in the AX register
00000010 The number 2
10010000 The next line is a number, put it in the BX register
00000011 The number 3
10110000 Add AX to BX and put the result in AX
11000000 Place the value of AX on the external data bus

A set of commands such as this is called a program.

Main Memory (RAM)

  • Referred to as RAM (Random Access Memory)
  • A collection of integrated circuits (chips)
  • Considered the “primary” storage for the CPU
  • Temporary storage for data and programs that are being accessed by the CPU
  • Volatile memory: contents are erased when the computer is switched off (or when power is lost)

Why use main memory?

Did you ever wonder why games take time to load? That is the time it takes to copy all the files of the game from the storage device (long-term memory) into the working memory of the main memory, which the CPU can access much faster and much more easily.

Memory Read/write speed
RAM 12,800 MB/s
SSD 456 MB/s

More RAM means more capacity to hold and process large programs and files. The maximum amount installed is limited by the motherboard and the operating system.

A short history

  • Early computers had RAM installed on the motherboard as individual chips. These were difficult to install and often became loose.
  • Designers then created memory modules: special circuit boards on which the memory chips are soldered.
  • Modules attach to the motherboard through memory slots, so memory can be added or replaced easily.

Main Memory Features

1) Data rate

SDRAM

  • The original main memory was the Synchronous Dynamic Random Access Memory (SDRAM)
  • It is synchronized with the motherboard speed
  • For a 32-bit bus, if the motherboard runs at 100 MHz, the SDRAM speed was also 100 MHz × 32 bits of data sent/received

DDR SDRAM

  • The first leap in RAM technology was Double Data Rate RAM
  • For every tick of the motherboard clock, DDR sends/receives 2 bits of information instead of just 1
  • This “doubles” the speed: 2 × 100 MHz × 32 bits

How can we tell the generations apart? By the number of pins and the position of the notch.

Type Pins Notches Clock speed Rating by transfer rate Rating by bandwidth
SDRAM 168 2 100 MHz SD-100 PC-800
DDR 184 1 100 MHz DDR-200 PC-1600
DDR2 240 1 100 MHz DDR2-400 PC2-3200
DDR3 240 1 100 MHz DDR3-800 PC3-6400
DDR4 288 1 100 MHz DDR4-1600 PC4-12800
DDR5 288 1 100 MHz DDR5-3200 PC5-25600
TipDecoding the names

The “PC” number is the bandwidth in MB/s: it equals the transfer rate multiplied by 8 bytes (a 64-bit module). For example, DDR4-1600 × 8 = PC4-12800.

DDR2 and DDR3 both have 240 pins, so the notch position is what keeps you from installing the wrong one.

2) RAM capacity

  • Every stick of RAM has a capacity (in GB), which is the amount of information the RAM can store
  • The capacity depends on the size of the chips (1 Gb, 4 Gb, 16 Gb, etc.)
  • The capacity also depends on whether the RAM is SIMM or DIMM
SIMM (Single Inline Memory Module) DIMM (Dual Inline Memory Module)
Era Older type of memory module. Common in early computers (e.g. Pentium I) Modern type used in most computers today
Contacts One set of electrical contacts. Both sides of the stick are connected to the same circuit Separate electrical contacts on each side of the module
Chips A single row of memory chips Can hold chips on both sides, effectively doubling capacity (e.g. 2 GB → 4 GB)
Data path 32-bit 64-bit, leading to faster performance

SO-DIMM modules are smaller RAM sticks used in laptops.

Serial Presence Detect (SPD)

How can we get all the specs of the currently installed RAM sticks? Each RAM stick includes an SPD chip that stores detailed information about the memory, such as speed, size, manufacturer, and timings. A tool like CPU-Z can read the SPD chip, so you can view all the RAM specifications without physically opening your computer.

3) RAM channels

  • Most motherboards have a limited number of RAM slots, usually 2 or 4
  • RAM is typically sold in pairs of sticks to take advantage of dual-channel performance
  • With dual-channel memory architecture, the CPU can access data from two RAM sticks at the same time instead of just one. This doubles the data bandwidth, making the system faster and more efficient.

Motherboards with four slots usually label them A1, A2, B1, B2:

  • Slots A1 and A2 belong to one memory channel
  • Slots B1 and B2 belong to the second channel
  • To activate dual channel, install the sticks in matching colored or labeled slots, e.g. A2 and B2
  • For the best performance, the RAM sticks should be identical: same size, speed, and brand if possible
WarningWhat happens if RAM is installed incorrectly?

If you put both sticks in the same channel (e.g. A1 and A2), the motherboard treats them as single-channel memory:

  • The system can only access one stick at a time
  • Memory bandwidth is cut in half
  • Overall performance drops (especially noticeable in gaming, video editing, or multitasking)

The PC still works, but you won’t be using it to its best capacity.

4) Memory redundancy and error checking

Memory errors happen when data is not stored or retrieved correctly from the RAM chips. Computers use different types of memory to detect and correct them.

Non-parity Parity ECC
Other name True parity Error checking and correcting
Detects errors? No Yes Yes (multiple-bit errors)
Corrects errors? No No Yes (1-bit errors)
How it works Nothing extra. If an error occurs, the OS has no way of knowing and data can be corrupted without warning Extra chips act as parity chips. A memory error is detected and the OS is informed Detects multiple-bit errors and corrects 1-bit errors automatically
Cost Cheapest, works fine for most applications Middle Most expensive

5) RAM latency

Latency is the small delay that occurs when the memory controller begins accessing a line of data from RAM. RAM with lower latency responds faster, while RAM with higher latency takes slightly longer to deliver data.

NoteLatency is a general concept

In physics and engineering, latency is a time delay between the cause and the effect of some physical change in a system. It is a consequence of the limited velocity at which any physical interaction can propagate.

Remember from Class 2: CRT monitors have lower latency than LCD/LED monitors because electrons travel faster in a vacuum than through digital circuits.

Virtual Memory

Every computer can use a portion of its hard drive as temporary RAM when the system runs out of physical memory. This is called virtual memory, and it uses a section of the drive known as a swap file or page file.

When the computer’s real RAM becomes full, the operating system moves (“swaps”) some data or inactive programs from RAM to the page file. This frees up space in RAM for the programs you are currently using.

Example

Assume your computer has 4 GB of RAM and several programs installed on your hard drive (A, B, C, D).

  1. You are running programs A, B, and C, and they fill the RAM.
  2. You want to run program D, but there is no more free RAM.
  3. A page file on your hard drive acts as a temporary storage box. The least-used program (say B) is swapped out of RAM into the page file.
  4. Program D can now run in the freed space.
  5. Later, if you try to use B again, it cannot run from the page file. Another less-used program must swap out, and then B is swapped back into RAM.

WarningDisk thrashing

Swapping is invisible to the user, but it takes time and Windows will slow down. If the page file is accessed too frequently, you may notice the hard drive LED going crazy. This is called disk thrashing, and it indicates that the computer would benefit from more RAM.

Exam question: Why is virtual memory not ideal?

CautionExpand to see the answer

Because the hard drive is much slower than RAM. Every swap costs time, so the whole system slows down, and when the page file is accessed too often the computer suffers from disk thrashing. The real fix is to install more physical RAM.

Key takeaways

ImportantRemember
  • The chipset controls data flow between CPU, memory, storage, and peripherals, and it determines which hardware is compatible.
  • In modern systems the northbridge is inside the CPU and the PCH replaces the southbridge.
  • Bus throughput = width × speed.
  • A CPU is made of an ALU and a Control Unit, plus registers and buses, and uses pipelining to work on several instructions at once.
  • Choose a CPU by socket (PGA/LGA), clock speed, cores, and cache.
  • Cache (SRAM) is small, fast, and expensive. RAM (DRAM) is larger, slower, and cheaper. Both are volatile.
  • Install RAM in matching channel slots to get dual-channel performance.
  • Virtual memory extends RAM with the hard drive, but it is much slower.
